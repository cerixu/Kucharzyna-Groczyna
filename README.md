# Kucharzyna Groczyna

Nowa, niezależna wersja aplikacji Kucharzyna oparta na odzyskanym projekcie z sandboxa Groka.

## Zasada projektu
To repozytorium jest całkowicie oddzielone od starego repozytorium Kucharzyny.

### Plan
1. Import odzyskanego kodu.
2. Uporządkowanie projektu i uruchamialnego buildu.
3. Audyt funkcji i błędów.
4. Test aplikacji.
5. Rozwój etapami, z testem po każdym etapie.

Nie usuwamy ani nie nadpisujemy starej Kucharzyny.
